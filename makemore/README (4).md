# makemore

| Notebook | Model | Loss (train) |
|---|---|---|
| [01_bigrams](01_bigrams.ipynb) | Bigram (counting) | 2.454 |
| [01_bigrams](01_bigrams.ipynb) | Bigram (neural net, 1 linear layer) | 2.490 |

Data: `data/names.txt` from [karpathy/makemore](https://github.com/karpathy/makemore).
